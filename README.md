# Rock Paper Scissors Game 🎮

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

[Play the Game](https://ilma9261.github.io/rock-paper-scissors-game/)

## 📌 About the Project

This is a browser-based Rock Paper Scissors game where the player competes against the computer.

The computer randomly selects Rock, Paper, or Scissors, and the result is displayed based on the rules of the game.

## ✨ Features

- 🎮 Play Rock Paper Scissors against the computer
- 🤖 Computer makes a random choice
- 🏆 Displays the winner of each round
- 📊 Keeps track of the player and computer scores
- 🖼️ Interactive images for Rock, Paper, and Scissors
- 📱 Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
